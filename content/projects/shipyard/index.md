## Для чего

Правила, по которым проект живёт с агентами, обычно копируются из репозитория
в репозиторий и расходятся. Shipyard выносит их в две части: плагин Claude
Code с навыками и шаблон репозитория с файлами процесса. Исправление в навыке
приходит во все проекты через `/plugin update`.

## Плагин shipyard

Шесть навыков, каждый срабатывает в свой момент:

- **task-stack** ведёт стек задач: перед задачей крупнее однострочного фикса,
  при блокировке и при выпуске.
- **lane-discipline** разводит параллельных агентов, чтобы их работа не
  пересекалась.
- **ci-gates** отличает зелёный PR от того, что только выглядит зелёным, и
  находит обязательные проверки, которые не запустились.
- **issue-bookkeeping** сверяет задачи в трекере с тем, что ушло в main.
- **deploy-verify** выкатывает релиз на хост и проверяет, какая версия там
  работает.
- **release-audit** проводит аудит продукта перед релизом.

Команда `/bootstrap` один раз настраивает свежий репозиторий из шаблона:
заполняет плейсхолдеры, пишет первый ADR и открывает первую задачу.

Навыки берут факты о проекте из именованных разделов `CLAUDE.md`. Если нужного
раздела нет, навык останавливается и сообщает об этом, вместо того чтобы
отработать с пустым значением по умолчанию.

## Шаблон project-skeleton

GitHub-шаблон, который даёт проекту процесс с первого коммита и больше ничего:
без фреймворка, пакетного менеджера и линтера.

- `specs/tasks/` — стек задач, по файлу на задачу, без общего индекса, на
  котором сталкиваются ветки.
- `.claude/CLAUDE.md` — рабочее соглашение из пяти правил и разделы, которые
  читают навыки.
- Проверка заголовка PR на Conventional Commits на POSIX shell, со своими
  тестами.
- `docs/adr/` — журнал архитектурных решений.

Для монорепозиториев есть отдельный плагин `shipyard-monorepo`. Он
необязателен: shipyard работает и без него.

## Начать

```sh
gh repo create my-project --template kkucherenkov/project-skeleton --private --clone
```

Затем в сессии Claude Code:

```text
/plugin marketplace add kkucherenkov/shipyard
/plugin install shipyard
/bootstrap
```
